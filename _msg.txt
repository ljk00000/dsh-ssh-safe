fix: CI failed on Node 20 and on every non-Windows runner

Three separate causes, none of which the local suite could show:

1. `node --test "test/*.test.js"` needs Node 21+. On Node 20 the quoted pattern
   is a literal path, so the runner printed "Could not find .../*.test.js" and
   exited 1 -- the windows-20 and ubuntu-20 jobs. `node --test` with no path
   uses automatic discovery, which works on every version in the matrix.

2. The audit write-failure test used '\\\\?\\invalid\\path', a Windows-only invalid
   path. On Linux that is an ordinary relative directory name, so the write
   succeeded and the assertion failed. It now writes under a path that sits
   inside an existing file, which fails with ENOTDIR everywhere.

3. The helper tests stored real DPAPI ciphertext, so on Linux the helper exited
   2 by design and four tests failed. The storing tests now skip without DPAPI,
   and a test asserts the refusal itself: it must not silently store a readable
   password and must name the environment-variable alternative.

The CI workflow had never been run before now. Tests: 217 passing, 5 skipped.
