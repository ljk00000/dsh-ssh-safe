fix: tool output was never asserted on, and three defects shipped in one round

1. ssh_config omitted pipeToShell and healthCheckTimeoutMs. The tool exists to
   report what is in effect, and it was itself incomplete: the setting added to
   govern pipeline refusals was the one you could not inspect. Both are listed
   now, and the tool warns at runtime if a Config key is ever missing from the
   table.

2. A pipeline refusal said 'Adjust denyPatterns' -- advice that can never work,
   because denyPatterns does not govern pipelines. The remedy now names
   pipeToShell for pipelines and denyPatterns for patterns.

3. The audit log wrote error/path/bytes/entries/truncated/redacted/ms and
   rendered none of them, so a failed operation showed the word 'error' with no
   cause. All detail fields are shown, on an indented second line.

4. ssh_doctor reported 'ok' for a credential it never checked: an env-key
   pointing at a missing file looked healthy until the connection failed. It now
   checks existence, non-emptiness and key shape, and that an agent socket
   exists.

5. Relative paths containing '..' are refused. SFTP resolves them against the
   login directory, which depends on sshd configuration and is not knowable
   here, so '..' would escape wherever the caller assumed.

6. README documented 16 of 19 settings; the three missing ones are added, as is
   the ssh_list path semantics.

7. test/tools.test.js: 12 tests that call apply() and assert on what each tool
   returns. Defects 1, 2 and 4 are exactly the class this catches, and defect 1
   was invisible to every existing suite.

Tests: 146 passing, 4 skipped. Typecheck clean.
